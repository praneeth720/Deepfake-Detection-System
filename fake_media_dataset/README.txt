SYNTHETIC FAKE MEDIA SET

This folder contains synthetically generated media for software testing only.

Structure:
fake/
  image/  -> synthetic portrait images
  audio/  -> synthetic waveform audio (WAV, 16 kHz, mono)
  video/  -> short synthetic portrait videos (MP4)

IMPORTANT:
These are NOT samples from a recognized deepfake benchmark dataset.
They should NOT be described in an IEEE paper as a benchmark dataset or as
evidence of model accuracy on real-world deepfakes.

For a paper, describe them as "synthetically generated test samples" or
"controlled functional-test samples" if you use them for testing.
